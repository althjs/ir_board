# 하드웨어 — 배선 가이드

## 부품 (BOM)
| 부품 | 비고 |
|---|---|
| RP2040 보드 | Raspberry Pi Pico / Pico-Zero / RP2040-Zero 등 (USB 네이티브) |
| IR 수신 모듈 | VS1838B / TSOP1838 류 3핀 (OUT/VCC/GND) — *수신 기능용* |
| IR LED (940nm) | *발신 기능용* |
| NPN 트랜지스터 | 2N2222 / 2N3904 / S8050 / BC337 — IR LED 구동 |
| 저항 | 1kΩ(베이스), 47Ω 내외(LED 전류제한) |

> KY-005 류 **3핀 IR 송신 모듈**(GND/VCC/DAT)을 쓰면 트랜지스터·저항 없이 바로 연결 가능.

## 핀 배치
| 용도 | RP2040 핀 |
|---|---|
| IR 수신기 OUT | **GP0** |
| IR LED (발신) | **GP15** |
| 전원 | 3V3 (수신) / 5V·VBUS (발신) |
| GND | 공통 |

- 신호선은 펌웨어 상단 `IR_RX_PIN` / `IR_TX_PIN` 으로 바꿀 수 있습니다.

## 수신부 배선 (3핀 모듈)
```
IR 수신모듈    RP2040
  OUT  ───────► GP0
  VCC  ───────► 3V3
  GND  ───────► GND
```
수신기는 평소 HIGH로 대기, 캐리어 감지 시 LOW로 떨어집니다(내부 풀업).

## 발신부 배선 (IR LED + 트랜지스터)
```
 VBUS(5V) ──► IR LED ⊕─⊖ ──► [47Ω] ──► C (컬렉터)
 GP15     ──► [1kΩ] ──────────► B (베이스)
 GND      ──────────────────────► E (이미터)
```
- **5V(VBUS)는 LED 쪽에만** 연결 — GPIO엔 절대 5V 넣지 말 것(3.3V 전용).
- 거리 더 원하면 47Ω → 33Ω. 3V3 사용 시 33Ω 내외.
- GP15가 38kHz로 트랜지스터를 구동 → LED 점멸 → 적외선 송출.

### KY-005류 3핀 모듈을 쓰는 경우
```
모듈      RP2040
 DAT ───► GP15
 VCC ───► 5V
 GND ───► GND
```

## 구성 옵션
- **발신 전용(폰용 동글)**: 발신부(GP15)만 — 수신기 불필요
- **수신+발신(캡처+테스트)**: 둘 다 연결
- 공통 GND 하나로 수신/발신 GND를 함께 묶으면 됩니다.

## 자가진단 (루프백)
수신부와 발신 LED를 서로 보이게 두고 발신하면, 보드가 **자기 신호를 수신**해 `RAW(..)`를 출력합니다 → 수신·발신 동시 확인. [zbd.kr/ir/debug](https://zbd.kr/ir/debug) 의 "루프백" 버튼으로 테스트 가능.

## 참고
- 940nm IR LED 권장. 캐리어 38kHz(NEC 등 대부분), 일부 기기 36/40/56kHz.
- 발신은 펄스 구동이라 평균전류가 낮아 트랜지스터/LED 발열 거의 없음.
- USB 24시간 상시 연결해도 무방(플래시에 기록 안 함).
